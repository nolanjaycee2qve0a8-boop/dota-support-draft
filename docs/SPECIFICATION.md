# Specification

**Dota Support Draft Assistant** is an explainable Dota 2 draft assistant for an individual Position 4/5 player. Given manual or future collected draft picks, it will eventually recommend support heroes using patch-aware public data, composition context, and optional personal performance.

DOTA-001 intentionally excludes live data ingestion, final weights, full draft UI, memory access, injection, gameplay automation, and account services.
